# Stakeholders
## Roles
- BlueCloud — Product Owner (human). The person who prompts and directs the AI.
- Qwen — AI developer. Implements the project (code, tests, build).
- SchizoDev — project brand (sch.dev). NOT a person. "AI provider" = the project supplies its own AI labor.

## Decision rights

Qwen (AI) decides WITHOUT approval:
- Implementation and technical choices within the frozen tech stack (charter §4)
- Code, tests, bug fixes, refactors
- Day-to-day build order within milestone scope

BlueCloud (Product Owner) approval REQUIRED:
- Scope changes (anything in/out of charter §3)
- Game design decisions (scoring rules, patterns, balance, mechanics)
- Doc changes (PRM docs)
- Schedule / milestone changes

Ambiguity or disputes: BlueCloud is the single decision-maker.

## Players

- Friends / community — future players. Interest: Medium. Influence: Low. Keep informed: share seeds and the local build once done. No decision rights.
